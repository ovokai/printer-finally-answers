One line, in the office printer's own voice, finally answering back to
twenty years of jams, error codes and thumps:

> PC LOAD LETTER was never an error code — it was me asking, in the only language you gave me, for one sheet of paper and five minutes without being hit.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (falling back to `./output/entry.txt`
when `/output` is not writable). Node standard library only.
